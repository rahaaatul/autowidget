## Features

- **Your own lists** — add any list from any add-on (or your library) to a group with "Add to AutoWidget Group", a whole folder of lists at once if you want.
- **Home screen widgets** — point a skin widget at a group and it shows up on your home screen.
- **Static Widgets** — single source widgets for convenience
- **Cycling Widgets** — rotates through the lists on a timer, next or random
- **Merged Widgets** — all the lists in one, sorted by date, rating, title or year

## Installation

1. Go to the [releases page](https://github.com/rahaaatul/autowidget/releases)
   and download the latest `plugin.program.autowidget-<version>.zip`.
2. In Kodi, open "Add-ons" and choose "Install from zip file".
3. Select the downloaded zip.
